Cara Menginstal Microsite di Berbagai Device:

📱
Android (Chrome / Edge / Samsung Internet):

Klik tombol "INSTAL APP" di pojok kanan atas, atau buka menu browser (titik tiga ⋮) > pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama".

🍏
iPhone & iPad (iOS Safari):

Ketuk tombol Bagikan (Share) di bilah bawah Safari, lalu gulir ke bawah dan pilih "Tambah ke Layar Utama (Add to Home Screen)".

💻
Desktop (Windows / macOS di Chrome / Edge):

Klik ikon instal di address bar browser sebelah kanan, lalu pilih "Instal".

Konfigurasi Backend Google Apps Script: URL Web App dan Lokasi Booth diatur oleh admin di file js/api.js (SCRIPT_URL) dan google-apps-script/Code.gs (CONFIG.BOOTH_LOCATION).
Data skor, tier hadiah, nama peserta, dan link sertifikat otomatis terakumulasi di Google Sheet & Drive saat peserta memutar speedometer.
